# DBSyncTool 布局优化方案

## 目标

把当前页面从“表单堆叠 + 多层卡片”调整为更适合数据库同步工具的工作台布局：信息更密、步骤更清楚、结果更像日志和差异查看器，减少大面积浅灰卡片带来的廉价感。

## 当前问题

1. 主窗口顶部栏和左侧栏都使用深色背景，视觉重量过大，内容区显得像被压在右侧。
2. 导出、比对页面都用纵向 `StackPanel` 串联多个 `Border`，页面很长，关键操作需要上下滚动。
3. 比对页的“加载快照、选连接、选表、执行、预览、导出”都在同一纵向流里，用户很难一眼判断当前处于哪一步。
4. 表格区域仍然像表单嵌套列表，缺少工具软件常见的表头、筛选、批量操作栏和结果区。
5. 差异预览虽然改成日志式，但仍放在独立块里，和操作区的关系不够清晰。
6. 颜色主要是深蓝灰和浅灰，层级靠边框堆出来，缺少稳定的设计令牌。

## 设计方向

### 1. 主窗口改成“轻导航 + 工作台”

建议保留左侧导航，但弱化顶部栏：

- 顶部栏高度从当前 `Auto + 24px 标题` 降低到 44px 左右。
- 顶部只放产品名、当前连接状态、全局提示入口。
- 左侧导航宽度从 200 调整到 176，背景从深色改为浅底或中性灰。
- 底部日志栏保留，但高度固定，作为全局状态输出。

推荐结构：

```text
┌────────────────────────────────────────────────────────────┐
│ DBSyncTool                 当前页标题 / 当前连接 / 状态       │
├──────────────┬─────────────────────────────────────────────┤
│ 导航          │ 页面工具栏                                   │
│              ├─────────────────────────────────────────────┤
│ 连接管理      │ 主工作区                                     │
│ 导出快照      │                                             │
│ 加载比对      │                                             │
│ 历史记录      │                                             │
├──────────────┴─────────────────────────────────────────────┤
│ 就绪 | 最近日志                                               │
└────────────────────────────────────────────────────────────┘
```

### 2. 比对页改成三栏工作流

比对页是当前最复杂页面，建议改为固定三段：

```text
┌────────────────────────────────────────────────────────────┐
│ 工具栏：选择快照 | 密码 | 选择连接 | 加载表 | 开始比对 | 生成脚本 │
├─────────────────────┬─────────────────────┬────────────────┤
│ 快照文件表           │ 当前数据库表          │ 比对摘要          │
│ 搜索/全选/反选        │ 搜索/全选/反选        │ 结构/数据/风险     │
│ 表列表               │ 表列表               │ 事务开关/导出报告   │
├─────────────────────┴─────────────────────┴────────────────┤
│ 差异预览 Tabs：结构差异 | 数据差异 SQL | 日志                  │
└────────────────────────────────────────────────────────────┘
```

落地建议：

- 第一行做成工具栏，不再分“1、2、3、4”大块。
- 快照表和数据库表左右并排，固定高度，内部滚动。
- 右侧放“比对摘要”，显示新增表、变更表、新增行、需人工处理项。
- 下方结果区使用 `TabControl`：
  - `结构差异`：树形日志行，可折叠。
  - `数据差异 SQL`：按表分组，展开后显示 SQL。
  - `运行日志`：显示加载、比对、生成脚本的时间线。

### 3. 导出页改成“连接 + 表选择 + 输出设置”

导出页建议从纵向三块改成左右布局：

```text
┌────────────────────────────────────────────────────────────┐
│ 工具栏：连接选择 | 加载表 | 开始导出 | 取消                    │
├──────────────────────────────────┬─────────────────────────┤
│ 表选择区                          │ 输出设置                 │
│ 搜索 + 全选 + 反选 + 模式批量       │ 密码                     │
│ 表格：选中/表名/行数/大小/模式/WHERE│ 文件夹                   │
│                                  │ 文件名                   │
│                                  │ 进度和摘要                │
└──────────────────────────────────┴─────────────────────────┘
```

落地建议：

- 表列表作为主区域，占 65% 宽度。
- 输出设置作为右侧属性面板，占 35% 宽度。
- 批量按钮放到表格顶部工具栏，按钮文案收短：
  - 全选
  - 反选
  - 全部结构+数据
  - 全部仅结构
- WHERE 条件列如果太挤，可以改成选中某行后在右侧编辑，第一版可先保留在表格内。

### 4. 差异预览统一成日志/代码风格

结果区不再使用单条卡片，统一成“日志容器 + 行”：

- 容器背景：`#0F172A` 或浅色 `#FFFFFF` 二选一，不混用。
- 建议先用浅色方案，和当前桌面工具风格更一致。
- 行高固定 28-32。
- 状态靠左侧色条或短标签区分，不靠大面积背景。

推荐结构：

```text
[新增表] dbo.Users                 列 12，索引 2
  [新增列] Name                    nvarchar(50) NOT NULL
  [注释] 用户表
[数据] dbo.Users                   新增 12 行，变更 0 行
  INSERT INTO ...
```

### 5. 设计令牌

建议先定义少量全局样式资源，别在每个页面重复写颜色。

```text
PageBackground        #F6F8FA
PanelBackground       #FFFFFF
PanelBorder           #DDE3EA
TextPrimary           #111827
TextSecondary         #6B7280
Accent                #2563EB
Success               #15803D
Warning               #B45309
Danger                #B91C1C
ToolbarHeight         44
PanelPadding          12
RowHeight             30
```

第一阶段不需要完整设计系统，只需要把硬编码颜色收敛到 `App.axaml` 或单独资源文件。

## 分阶段改造

### 第一阶段：低风险视觉整理

范围小，不改业务逻辑。

1. 主窗口顶部栏降高，左侧导航减宽。
2. 把页面外层背景改成统一 `PageBackground`。
3. 把各页面 `Border` 样式统一为 `Panel`，减少重复硬编码。
4. 差异预览保持现有数据结构，只调整为统一日志行样式。

验收标准：

- 不影响导出、加载、比对、生成脚本。
- 页面一屏内能看到主要操作区和结果区入口。
- 视觉上不再像多个浅灰卡片堆叠。

### 第二阶段：比对页重排

这是体验提升最大的一步。

1. 比对页顶部改为横向工具栏。
2. 快照表和数据库表改为左右并排表格。
3. 比对摘要移到右侧固定面板。
4. 结构差异和数据 SQL 放入下方 `TabControl`。

验收标准：

- 用户完成“选快照、选库、选表、比对、看结果、生成脚本”不需要大量滚动。
- 快照侧和数据库侧的勾选关系清楚。
- 部分表比对后，摘要、预览、报告保持一致。

### 第三阶段：导出页重排

1. 表选择改为主表格。
2. 密码、路径、文件名、进度放到右侧属性面板。
3. 批量模式按钮统一放在表格工具栏。
4. 导出摘要放到底部状态区或右侧面板底部。

验收标准：

- 加载表后，表列表成为视觉主角。
- 输出路径和文件名更容易确认。
- 大表和无主键状态更醒目。

### 第四阶段：细节增强

1. 表列表加搜索框内置占位和清空按钮。
2. 差异结果支持按状态筛选：全部、新增、变更、警告。
3. 生成脚本按钮旁显示预计 DDL/INSERT 数量。
4. SQL 预览支持复制按钮。

这些不是第一版必需项，建议等前面布局稳定后再做。

## 不建议做的事

1. 不建议做营销式首页或大标题欢迎页，这个工具是高频操作型软件。
2. 不建议继续增加卡片层级，当前问题正是层级靠卡片堆叠。
3. 不建议引入新的 UI 控件库，Avalonia 原生控件已经够用。
4. 不建议一次性重写所有页面，先改主窗口、比对页、导出页即可。

## 推荐落地顺序

1. 抽公共颜色和面板样式。
2. 优化主窗口导航和底部日志栏。
3. 重排比对页。
4. 重排导出页。
5. 最后统一连接管理、历史记录页面的小样式。

## 预期效果

改完后 DBSyncTool 应该更像一个数据库运维工作台：左侧导航轻，顶部操作集中，中间表格清晰，下方结果像日志和 SQL 查看器。用户能快速判断当前选择了哪些表、比对出了什么、将要生成哪些 SQL。
