# 10: 桌面 - 导出流程（阶段一 UI）

**Status:** ready-for-agent

**Blocked by:** 05 - 快照导出/加载 + AES-256 加密，06 - 行哈希指纹计算（SQL Server），09 - Avalonia 桌面脚手架 + 连接管理

**What to build:** 实现完整的阶段一 UI 流程，DBA 选择连接、配置表同步选项、设置密码后导出 .dbsync 文件。

- [ ] 导出向导步骤一：选择已保存的数据库连接（下拉列表）
- [ ] 导出向导步骤二：表选择界面
  - 表格列：复选框、表名、预估行数、数据大小（MB）、同步模式（结构 / 结构+数据）、WHERE 条件输入框
  - 支持全选、反选、按表名过滤
  - 无主键的表：同步模式列显示"⚠ 无主键，仅结构"，禁用数据选项
  - "结构+数据"行数超过用户配置阈值时，在选项变更时立即弹出确认对话框
- [ ] 导出向导步骤三：密码设置
  - 必填：加密密码（含确认输入）
  - 可选：密码提示（passwordHint，明文，明确标注"此提示将以明文保存在快照文件中"）
  - 选择导出路径和文件名
- [ ] 导出执行：显示实时进度（当前表 / 总表数、当前行数）、支持取消操作
- [ ] 导出完成后显示摘要（文件路径、文件大小、涉及表数量）
- [ ] 历史记录：将本次使用的连接和导出文件路径写入历史
