# 12: 桌面 - SQL 脚本导出 + 差异报告

**Status:** ready-for-agent

**Blocked by:** 08 - SQL Server INSERT 脚本 + 事务包装，11 - 桌面 - 加载快照 + 差异预览

**What to build:** 实现差异预览后的最终步骤：生成 Upgrade.sql 并导出，同时可导出供团队审阅的差异报告。

- [ ] 差异预览确认后，点击"生成脚本"调用 `GenerateUpgradeScript`，展示生成进度
- [ ] 保存 Upgrade.sql 文件选择对话框，默认文件名含时间戳（`Upgrade_20260901_143000.sql`）
- [ ] 生成完成后展示摘要：DDL 语句数量、INSERT 语句数量、总行数估计、文件大小
- [ ] 差异报告导出：支持 HTML 和 Markdown 两种格式，内容包含：
  - 快照元信息（导出时间、数据库类型）
  - 结构差异汇总表（按表列出变更类型和内容）
  - 数据差异汇总表（含新增/删除/变更行数，删除和变更标注"需人工审阅"）
  - 循环依赖警告列表
  - 无主键表跳过列表
- [ ] 历史记录：将本次生成的脚本路径写入历史，并在主界面"历史记录"页面展示（最近 20 条）
- [ ] 主界面历史记录页面：展示最近使用的连接和快照路径，点击可快速重新打开
