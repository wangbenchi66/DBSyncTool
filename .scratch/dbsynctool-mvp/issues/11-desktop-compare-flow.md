# 11: 桌面 - 加载快照 + 差异预览（阶段二 UI）

**Status:** ready-for-agent

**Blocked by:** 03 - Schema 比较器 + 外键拓扑排序，05 - 快照导出/加载 + AES-256 加密，07 - 数据比较器（仅 INSERT 逻辑），09 - Avalonia 桌面脚手架 + 连接管理

**What to build:** 实现完整的阶段二 UI 流程，开发人员加载 .dbsync 文件，连接测试库，查看结构和数据差异预览。

- [ ] 比对向导步骤一：加载快照文件
  - 文件选择对话框（过滤 .dbsync）
  - 密码输入框；若快照含 passwordHint，在输入框上方以提示文字显示
  - 解密成功后展示快照元信息（导出时间、数据库类型、涉及表数量）
- [ ] 比对向导步骤二：选择要比对的数据库连接（下拉，仅显示与快照数据库类型匹配的连接）
- [ ] 比对执行：读取当前库结构 + 计算实时哈希，显示进度
- [ ] 结构差异预览（树形视图，按表分组）：
  - 新增表（标绿）、删除表（标红，默认未勾选）、变更列/约束/索引（标黄）
  - 每条差异项可单独勾选/取消，控制是否纳入最终脚本
  - 存在循环外键依赖的表组：标注警告图标，提示需手动处理
- [ ] 数据差异预览（按表展示摘要）：
  - 新增行数量（将生成 INSERT，绿色）
  - 删除行数量（仅报告，灰色标注"不生成 SQL，需人工审阅"）
  - 变更行数量（仅报告，灰色）
  - 无主键表：标注"⚠ 已跳过数据比对"
- [ ] 历史记录：将本次使用的连接和快照路径写入历史
